# 《我跟》——30 秒电竞训练室短剧样稿

> **独立创作样稿，不是原剧本修复。** 沿用“陆沉、周野、秦教练”的人物名称和电竞训练室题材；下列对白与表演均在本次样稿创作阶段确定。未读取或改写项目保存数据，未核验实际角色图片，未生成图片/视频。
>
> 使用应用内 h3-prompt-writing 的两层流程：先完成剧本及摄影/表演规划，再用 H3 I2VA 结构表达。另使用刚修改的共享创作规则；不是让格式 skill 越权编剧情。

## 一、创作意图

**一句话故事：** 队员把队长的保护听成了不信任；教练问破问题，队长用一句“我跟”把指挥权交出去。

**情绪走向：** 带刺的质问 → 好意伤人 → 被问住 → 试探承诺 → 获得支持 → 实际一起行动。

**这场戏不证明他们赢了比赛，只证明他们开始共同承担决定。** 没有旁白、解释性字幕或煽情配乐。

## 二、剧本正文

**内景 · 训练室 · 夜**

周野把耳机沿桌垫推开，转向陆沉。他本来想把话说得很冲，临到最后一个字，却还是露了怯。

**周野：** 你是不是觉得，我只会送？

陆沉停住鼠标，看向他。回答出口时仍像在辩解。

**陆沉：** 我怕你又白白冲进去。

周野抬起下巴，把脸转开一点。陆沉看见了，后半句话的力气已经弱了，却来不及收回。

秦教练把手轻轻按在桌面上。他不拍桌，也没有替任何一方判输赢。

**秦教练：** 你替他打，还是让他打？

陆沉先看自己的鼠标，再看周野。周野原本刚要露出“教练站我这边”的表情，这时也不笑了。

陆沉转过椅子，正面朝向他，带着一点承认自己做过头的苦笑。

**陆沉：** 下一波，你来喊。

周野看一眼教练，再看回来。声音比刚才小了。

**周野：** 喊错了呢？

陆沉先点头，回答得很普通，没有故意压低嗓子。

**陆沉：** 我跟。

周野肩膀松下来，真正笑了一下。两人转回屏幕。他伸手拿起耳机，戴好，把手放上键鼠。陆沉已经准备好了，却等着他开口。

**周野：** 三、二、一，进！

周野先按键，陆沉紧跟。秦教练点了一下头。

屏幕里有运动与明暗变化，但不出现胜利提示。周野这次没有回头等陆沉下指令。

**结束。**

## 三、空间、声音与首帧承接

- 一张东西向长桌；陆沉坐西侧工位，周野坐东侧工位，两人均在桌北侧面朝自己的南向显示器。秦教练站桌西端。所有摄影机位留在两人交流轴线南侧；共享正面构图中，陆沉左、周野右。
- 三名说话人固定：S1 陆沉，较低、略干的青年男声；S2 周野，较亮的青年男声；S3 秦教练，清楚稳健的成年男中音。音色差异不是音色资产已配置的声明。
- 全片只有风扇底噪、耳机/衣料/椅子/键鼠声，以及剧本中的七句台词，无非叙事音乐。
- **4 个视频生成单元，8 + 7 + 8 + 7 = 30 秒。** 单元不等于摄影上只能有一个机位。各单元内部已提前规划必要切镜；动作、对白和场景时间始终连续。
- 只有 01-01 需要制作初始首帧。01-02、01-03、01-04 分别使用上一单元**已采用成片的实际尾帧**，不另生成首尾帧。各单元开头保留继承构图，再在规划时间点切镜；不能在 0 秒凭空换机位。
- 以下首尾状态是计划，不冒充实际截图核验结果。若成片尾帧不符合计划，例如耳机已提前戴上，先决定修复上一镜或修订下一镜；不能一面复用实际截图，一面要求下一镜从相反状态开始。

## 四、第一镜首帧生图提示词

一张完整的电影写实训练室画面，16:9，夜间室内。横向长桌后坐着两名年轻成年男性，陆沉在画面中左、周野在右；成年男性秦教练站在画面左侧的桌端。摄影机位于两名队员对话轴线的同一侧，越过低矮显示器边缘看见三人的脸、肩膀和一段桌面，不用高位斜俯场景资产图代替人物机位。
样稿造型建议：陆沉短黑发、深灰圆领训练服；周野略蓬松短发、袖口卷起的浅灰训练外套；秦教练短发、深色无标识运动夹克。三人面貌清楚且互不相似，服装无可读标志。这些是本样稿的新设定，并非已经核验过的项目资产；正式接入时以用户选定的真实角色图片替代。
陆沉右手搭在自己的鼠标上，脸正准备转向周野，眼神带着疑问。周野右掌已经触碰桌垫上的一副黑色头戴耳机，但耳机尚未移动；他的嘴唇微张、眉头扬起，正要发问，而不是沉默低头。秦教练视线落在两人之间，身体稍向桌边倾。两人的键盘、鼠标、显示器各一套，物体不重复。稳定顶灯让眼睛与嘴部清晰可读，屏幕冷光只是面部补光，肤色不过蓝。不要加入战术板、护腕、比赛奖杯、文字、字幕或其他人物；画面只记录开场瞬间，不画后续戴耳机的动作。

> 后三镜不提供会触发重绘的首帧生图词；其首帧输入就是前一镜采用视频的尾帧截图。

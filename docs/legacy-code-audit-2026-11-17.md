# GDream 旧品牌与投流模块清理记录

首次审计：2026-11-17。清理更新：2026-11-18。

## 当前结果

按“无需兼容旧用户数据”的范围，发布版本已移除广告投流功能与鲲鹏品牌兼容代码。代码定位先使用原源码目录的 CodeGraph，随后在独立发布仓库核对调用与修改，构建检查以发布仓库实际文件为准。

这些模块原先已包含在 GDream 源码中，并非合并 GitHub 目标仓库时混入。旧源码目录与外层私有仓库未在此次修改。

| 清理项 | 处理结果 |
|---|---|
| 广告投流工具 | 删除全部 7 个 `touliu_*` 工具及注册、可见性门控 |
| 投流技能 | 删除内置表单、提示词、产品元数据、工具栏条目及随包分发的技能目录 |
| 投流状态与界面 | 删除独立账户/指标状态仓库、数据面板、图表与导出入口 |
| 启动兼容 | 删除前端旧缓存键迁移模块、启动导入与 Rust 旧数据目录迁移及其辅助函数 |
| 目录与路径 | 删除 `.kunpeng` 的读写兼容、项目导入路径替换分支、素材扫描与清单回退、Tauri 显式权限 |
| 回归测试 | 移除旧品牌迁移专属测试；新增当前素材目录行为和权限范围测试，纳入 Harness 测试命令 |
| 文档 | 删除架构说明中的投流模块项；旧版截图和误入库投流实测记录已在前次清理移除 |

当前素材库只扫描 `.gdream/workspace`、`.gdream/projects`、`.gdream/aigc-memory` 和 `.gdream/outputs`，仍保留当前素材清单的元数据与去重行为。GDream 自身的缓存落盘、项目数据结构归一化及广告内容创作能力继续服务当前业务，不属于旧品牌迁移或广告账户投放功能。

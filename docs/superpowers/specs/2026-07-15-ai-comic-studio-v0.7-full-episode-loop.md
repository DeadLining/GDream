# AI Comic Studio v0.7.0: 整集 AI 成片闭环

## Capability

创作者输入一个主题和本次创作要求后，系统能够以 AI 为默认执行者完成一整集动态漫画：生成并确认剧本结构，建立角色参考，生产全部镜头画面、对白音频和镜头视频，合成整集 MP4，执行真实渲染质检，生成终审候选，并在服务端门禁通过后登记内部母版或发布记录。人工仍可在任一审核点介入，但不再需要逐镜头手工推动主流程。

## Fixed Constraints

- 整集闭环的最小完成条件是：本集所有镜头都有已激活视频，所有非空对白都有可用音频，整集渲染文件可读取且具有 MP4 签名，渲染质检 `overall_pass=true`，终审候选门禁 `ready=true`，发布记录持久化成功。
- AI 是默认执行者，不等于跳过质量门。角色参考、镜头画面和视频可由自动策略批准；任何关键失败、空产物、媒体签名错误或 QC 失败都必须阻断后续发布。
- 每次生成产生不可变资产版本；重试不得覆盖已存在的画面、音频、视频或整集候选。
- 整集编排必须按依赖顺序运行：角色参考 -> 画面 -> 画面审核 -> 配音 -> 视频 -> 整集合成 -> QC -> 终审候选 -> 门禁 -> 登记。
- 流程状态、阶段耗时、任务错误、生成资产和最终候选必须可恢复、可追踪、可重复查询。
- 现有手工工作台、逐镜头生成和人工审核继续可用；v0.7.0 不能强制迁移已有项目或删除人工控制。
- Provider 密钥继续由本地渠道配置持有，测试结果、日志和导出物不得包含明文密钥。

## Actors And Surfaces

- 创作者：在剧本创作入口输入主题，在整集生产面板启动、暂停、重试并查看阶段状态。
- AI 编排器：根据依赖图推进各阶段，执行默认审核策略，遇到阻断时停止并给出可操作原因。
- 审核者：在视觉审阅和审核发布页检查候选、要求修改、生成终审预览并登记。
- 运维者：在模型中心检查 LLM、图片、TTS、视频渠道及 Mock SSH 状态，查看失败调用和耗时。

## State Machine

```text
draft
  -> scripting
  -> structuring
  -> references
  -> panels
  -> panel_review
  -> speech
  -> videos
  -> rendering
  -> quality_review
  -> release_candidate
  -> release_gate
  -> published
```

任一执行阶段可以进入 `paused`、`failed` 或 `needs_review`。从失败恢复时只重跑失败阶段及其下游失效项，不重写已完成资产。

## Implementation Contract

### Inputs

- `theme`: 必填主题。
- `brief`: 可选创作要求。
- `target_duration_seconds`: 目标整集时长。
- `aspect_ratio`, `language`, `visual_style`: 项目级约束。
- `automation_policy`: 默认 AI 审核、人工确认点、预算和并发限制。

### Outputs

- 项目、剧集、场景、镜头和角色结构。
- 每个角色至少一个已批准且激活的主参考。
- 每个镜头的激活画面和激活视频。
- 每条非空对白的音频资产。
- 一个经过真实渲染质检的整集 MP4。
- 一个持久化终审候选、门禁快照和发布登记记录。
- 完整阶段耗时、模型调用与失败证据。

### Required Interfaces

- 复用现有剧本流式生成、结构解析、角色参考、画面、配音、视频、渲染、渲染质检和发布 API。
- 增加一个持久化的整集 AI 编排资源，负责依赖推进、恢复和幂等，而不是让前端用临时请求链承担生产状态。
- 真实模型 E2E 必须验证所有镜头和全部最终产物，不能只验证第一个镜头。

### Observability

- 每个阶段记录开始、结束、耗时、输入实体、输出资产、provider/model 和错误摘要。
- 工作台展示当前阶段、整集完成率、失败镜头、预计剩余工作和最终 QC。
- 终审候选必须关联生成它的渲染任务和渲染质检记录。

## Non-goals

- v0.7.0 不负责抖音、B 站、YouTube 等外部平台的真实上传；只登记发布记录。
- 不在本版本实现多供应商自动竞价或跨供应商自动降级。
- 不要求 3D 角色资产成为整集生成的硬依赖；3D 导演台仍是可选构图能力。
- 不允许无人监督地绕过关键 QC 或发布门禁。

## Release Gates

- 真实模型 E2E 从给定主题生成至少一集、多个镜头，并验证全部激活视频。
- 有对白用例验证 TTS；无对白用例验证流程不会产生伪造音轨要求。
- 整集 MP4 可播放、文件有效，渲染质检通过。
- 终审候选、门禁、批准和发布登记全部持久化。
- Web、API、Compositor 全量测试和构建通过。
- 版本清单只在上述门槛通过后统一升级为 `0.7.0`。

## Handoff

实现顺序：先升级真实模型 E2E 合同，再增加持久化整集编排器，随后接入工作台一键入口和恢复 UI，最后执行真实渠道验收与版本升级。

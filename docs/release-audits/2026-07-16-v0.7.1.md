# AI Comic Studio v0.7.1 Release Audit

Release branch: `feat/v0.7-full-episode-loop`

## Fixes

- Narration voice is configurable through `QWEN_TTS_NARRATOR_SPEAKER` or `AI_COMIC_QWEN_TTS_NARRATOR_SPEAKER`.
- The configured narrator speaker is injected through the model runtime into speech synthesis.
- Episode subtitle cues use absolute timeline offsets across all scenes and shots.
- Rendered MP4 files embed a Chinese `mov_text` subtitle stream while preserving the burned-in review subtitles.
- Empty or out-of-shot subtitle cues do not create invalid tracks.
- The generated UTF-8 SRT sidecar is retained next to the render for export and debugging.

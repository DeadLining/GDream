# AI Comic Studio v0.6.0 Release Audit

Release branch: `feat/3d-director`

## Feature Gates

- Each existing scene owns at most one persistent `DirectorStage`.
- Scene objects are shared across shots; each shot owns an independent versioned camera.
- Object, environment, and camera mutations use optimistic versions and bounded revisions.
- The workspace renders deterministic Three.js placeholders without external model assets.
- Desktop supports object transform controls; mobile keeps preview and numeric camera controls.
- MiniMax director suggestions remain drafts until users review and apply explicit shot fields.
- Applying a suggestion preserves panel, video, speech, and render assets.
- Camera previews reject invalid, oversized, escaped, and visually blank PNG captures.
- Episode deletion removes registered director preview assets and contained local files.

## Dependency Audit

- Python: no known vulnerabilities. The local `ai-comic-studio-api` package is not published on PyPI and was skipped as expected.
- npm: two moderate findings for `postcss <8.5.10`, bundled by Next 16.2.10.
- npm's automatic fix proposes a breaking downgrade to Next 9.3.3 and was not applied.
- The affected CSS stringify path is not reachable from user-provided content: this local app does not accept custom CSS and React renders imported/model text as text values.
- Upgrade to the first patched stable Next release and rerun the audit when available.

## Known Follow-ups

- External GLB asset generation/retrieval, skeletal posing, motion generation, and image-to-3D are deferred.
- Stage-layout suggestion application currently focuses on strict persisted drafts and shot composition fields; richer object-level AI diff application is deferred.
- Restore the AI streaming and manual parse entry inside the newer persistent Script Library surface; the legacy standalone import workflow is no longer the active workspace.
- Add named transform modes for translate, rotate, and scale after production interaction testing.

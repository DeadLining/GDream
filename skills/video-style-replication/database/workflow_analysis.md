# 视频风格复刻：可复用的迭代分析示例

> 本文是教学用的示例流程，不是用户对话、项目生成记录或效果验收报告。角色、场景与参数均可替换；参数只作试验起点，不代表实测结果。

## 一、输入与目标

- 调用者提供有权使用的参考视频；从中选取代表性的光影与构图。
- 可选：调用者提供有权使用的虚构角色设定图，用于跨分镜一致性，不绑定任何个人照片或身份。
- 准备包含角色、场景、分镜与写实约束的计划 JSON。
- 示例目标：在自然光的山地科幻环境中，生成一组写实、风格统一的故事板。
- 视频、角色图和输出目录由调用者指定，不依赖特定桌面目录或历史文件名。

## 二、示例迭代流程

### 1. 写实基准

先生成一版材质、光影、色彩均自然的基准图。

检查：皮肤与金属是否具有可信纹理，服装是否连续，角色比例与构图是否稳定。
不预设某个模型或版本一定更好，以实际输出为准。

### 2. 提取视频风格

使用豆包等多模态分析工具，分别记录：

1. 光影：主光方向、补光来源、体积光与暗部细节。
2. 色彩：色温、饱和度、对比度与局部跳色。
3. 材质：颗粒、反射、磨损和边缘锐度。
4. 构图：景别、透视、空间层次与主体占比。

不要一次性照搬所有参数。动态视频的流动感不等于单帧的锐化或模糊强度。

### 3. 受控增强

保留基准版的写实约束，只改变少量风格因素。
以下数值是相对主观强度的示例，不是跨模型通用的物理量：

| 调整项 | 示例起点 | 检查重点 |
|--------|----------|----------|
| 自然随机光斑 | +15% | 光源方向一致，不遮挡主体 |
| 暗部透气度 | +10% | 保留灰阶，避免整体泛灰 |
| 实拍颗粒感 | +8% | 不吞噬细节，不过度锐化 |
| 运动模糊 | ≤10% | 仅用于前景或远景，保持主体清晰 |
| 冷暖渐变 | ≤5% | 环境色过渡自然 |
| 高光偏移 | ≤8% | 符合金属或湿润材质的反射逻辑 |

### 4. 对比与定位

对照参考视频的代表帧、写实基准和增强候选，逐项判断差距。
若增强后出现塑料材质、高饱和、过度磨皮或游戏截图感，降低相关参数；不要仅凭版本名判断质量。

可选地使用 Gemini 等图像工具制作候选，但生成前应明确成本和输出数量。
需要修改时，依据本次评估决定是否生成新候选，不自动重复已执行的付费调用。

### 5. 平衡与无文字检查

把表现较好的角色一致性、光影逻辑和材质处理组合成候选方案。
需要纯视觉故事板时，明确禁止字幕、编号、标签、水印与说明文字。

逐格检查 3×3 布局、人物一致性、叙事连续性和文字残留，不宣称未验证的满意度或匹配率。

## 三、核心方法论

### 三层分析框架

- 第一层：提取参考视频的光影、色彩、材质与构图系统。
- 第二层：对比候选图，区分实际差距与预设偏好。
- 第三层：调整少量参数，验证真实感与风格是否同时改善。

```text
输入与约束 → 写实基准 → 风格分析 → 受控增强 → 对比检查
                                              ↓
                            保留有效调整 → 无文字检查 → 确认输出
```

### 边界与质量标准

- 写实感优先：材质、光影、色彩应自然可信。
- 保持透视与比例，不用无依据的强对比、高饱和掩盖问题。
- 避免过度磨皮、锐化和不符合光源方向的高光。
- 静态图可以表达某一帧的构图与氛围，不能保证复现视频的时间维度、空间视差或情绪递进。
- 任何增强幅度都需要按模型和实际素材验证，不能保证固定效果百分比。

## 四、可替换的风格示例

示例环境为虚构的山地遗迹，不对应某位用户的创作项目：

- 主光：中性偏暖的侧向散射日光。
- 辅光：植被反射的微冷环境光，暗部保留层次。
- 色彩：低饱和灰绿、灰蓝和暖黄，少量野花作为跳色。
- 材质：细微胶片颗粒、真实金属磨损、自然布料与植物纹理。
- 空间：近景草叶、中景角色、远景山脉和虚构建筑遗迹。

## 五、产物与复用

按调用者指定的项目目录保存以下产物，不需要原项目的文件名：

- 参考风格分析 JSON。
- 分镜计划 JSON。
- 基准图、增强候选与确认后的故事板。
- 对比分析及调整建议。

本目录中的 `awakening_prompt_no_text.md` 提供可替换的无文字九宫格示例提示词。
将角色、环境和风格替换为当前任务素材后再使用。

## 六、验证与记录

每次迭代记录实际输入、选用模型、参数和评估结果；不要复制私人反馈或个人参考图文件名进入共享知识库。
调用次数、费用、耗时、满意度与匹配率应来自实际记录；本示例不提供历史统计。

核心经验：先建立写实基准，再以可解释的小步调整对齐风格；有证据才保留修改。

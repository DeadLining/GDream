# 无文字九宫格故事板：可替换的虚构角色示例

> 教学示例，不对应私人创作记录或具体人物。默认角色为原创虚构成年探索者；如提供角色设定图，应使用有权使用的素材，并以本次输入为准。下列增强百分比仅为提示词中的相对强度示例，不是效果保证。

【核心指令】
生成一张包含9个分镜头的九宫格故事板图片（3行3列，细线分隔）。
用同一名原创虚构成年探索者演示“苏醒—观察—起身—探索”的连续叙事。
若有角色设定图，在各格中保持其设计一致；未提供时使用下方虚构设定，不要求复刻任何真实人物的身份或面孔。

**重要：图片中不要出现任何文字、字幕、编号、标签、水印或说明文字。**

【一、角色一致性与真实感】

- 示例角色：成年山地探索者，深色短发、深棕瞳孔、自然肤色；可按当前角色设定整体替换。
- 所有分镜保持面部比例、发型、服装与装备一致。
- 面部保留真实毛孔和自然皮肤光泽，不做过度磨皮、锐化或夸张美化。
- 服装：浅色做旧探索服、轻型护甲、耐磨长裤与护膝。
- 装备：机械手套、背包和折叠登山杖，固定位置保持连续。
- 磨损、泥土和汗珠应符合动作与环境，不绑定特定人物的伤痕特征。

【二、光影系统】

- 基础光源：上午侧向散射日光，约4800K，中性偏暖。
- 暗部保留灰阶层次，避免死黑；反射符合材质与光源方向。
- 如有参考风格，借鉴其光影逻辑，不强行照搬动态视频的每个参数。

安全增强示例：
- 自然随机光斑 +15%，模拟叶片缝隙的透光。
- 暗部透气度 +10%，保留局部细节。
- 细微实拍颗粒感 +8%，不吞噬纹理。

谨慎增强示例：
- 前景植物、远景边缘的运动模糊 ≤10%，主体保持清晰。
- 画面边缘冷暖渐变 ≤5%，避免滤镜感。
- 金属和湿润区域高光偏移 ≤8%，符合反射逻辑。

这些强度需要按实际模型和输出调整，不是模型专用 API 参数。

【三、材质与色彩】

- 金属：自然划痕、掉漆与银灰底层，湿润反光不呈塑料感。
- 皮肤：自然肌理、汗珠和少量泥点，避免光滑蜡像质感。
- 植物：叶片、露水、草屑具有微观细节。
- 布料：纤维、褶皱与磨损符合动作，连续镜头不换装。
- 色彩：低饱和灰绿、灰蓝、暖黄，少量野花跳色，整体自然。

【四、可替换的虚构环境】

高山草甸与森林边缘：野花、针叶林、远处山脉，植被覆盖的科幻拱门和废弃观测站。
这些是示例场景元素，可整体替换，不要求提供任何旧项目的参考图或文件名。

【五、九宫格分镜内容（3×3）】

分镜1（左上）：脸部特写
- 景别与角度：脸部占约65%，俯拍20°。
- 内容：探索者闭眼躺在草甸，发梢带露水。
- 光影：侧向散射光，自然光斑与细微颗粒。
- 细节与叙事：皮肤真实，少量泥点，表现尚未苏醒。

分镜2（中上）：机械手套特写
- 景别与角度：手部占约60%，平拍。
- 内容：手指轻微活动，触碰湿润泥土与草叶。
- 光影与材质：自然散射光，金属反光柔和，关节有泥粒。
- 叙事：意识开始恢复。

分镜3（右上）：面部近景
- 景别与角度：俯拍10°。
- 内容：探索者睁眼，看向自己的手。
- 细节：眼睛反光自然，表情克制，与首格保持同一虚构角色设计。
- 叙事：逐渐确认状态。

分镜4（左中）：撑地中景
- 景别与角度：上半身中景，平拍微仰5°。
- 内容：手掌撑地，缓慢抬起上半身。
- 环境与材质：草叶遮挡少量前景，护甲与布料受力可信。
- 叙事：尝试起身。

分镜5（中中）：坐起中景
- 景别与角度：上半身中景，平拍。
- 内容：完全坐起，低头检查机械手套，背包与登山杖可见。
- 光影与细节：暗部透气，装备位置与前格连续。
- 叙事：确认身体与装备状态。

分镜6（右中）：观察中景
- 景别与角度：平拍。
- 内容：转头观察森林和周围地形。
- 环境：草甸、针叶林、淡蓝天空，少量草屑落下。
- 叙事：辨认陌生环境。

分镜7（左下）：站立全景
- 景别与角度：全景，俯拍15°。
- 内容：站起，拍掉衣物上的草屑。
- 环境与材质：浅色探索服与绿色草甸形成清晰层次。
- 叙事：恢复行动能力。

分镜8（中下）：前行远景
- 景别与角度：远景，平拍。
- 内容：背影朝森林边缘前行，前方出现植被覆盖的拱门。
- 光影与细节：远景轻微柔化，主体轮廓和装备连续。
- 叙事：开始探索。

分镜9（右下）：远望大全景
- 景别与角度：大全景，仰拍10°。
- 内容：探索者在高处望向远方废弃观测站。
- 环境与影调：山脉、遗迹与草甸构成空间层次，明亮通透但不过曝。
- 叙事：确立下一步目标。

【六、安全边界与负面提示词】

不要动漫感、二次元渲染、光滑塑料材质、无依据的高饱和、强对比、过度磨皮或锐化。
不要修改透视比例，不要跨格改变角色外观、服装和装备，不要用动态模糊掩盖结构问题。
不要文字、字幕、编号、标签、水印、场景标注；只保留纯视觉画面。

【七、布局与验收】

- 3行3列，9格按从左到右、从上到下阅读，细线分隔。
- 整体目标画幅：3072×3072像素，1:1比例；单格约1024×1024像素。
- 验收：同一虚构角色、动作连续、材质可信、光源一致、无文字。
- 目标是可读的故事板与受控风格，不宣称固定美化程度、匹配率或用户满意度。
